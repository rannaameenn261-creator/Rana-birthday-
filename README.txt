# Rana Birthday Website 🎂

## Files
- `index.html` — page content
- `style.css` — luxury design
- `script.js` — countdown and interactions
- `assets/` — Rana's photos

## GitHub Pages
1. Create a public GitHub repository, e.g. `rana-birthday`.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Your website will appear at `https://YOUR-USERNAME.github.io/rana-birthday/`.

## Before publishing
Open `index.html` and replace:
- `YOUR DATE`
- `YOUR TIME`
- `YOUR VENUE`
- the `GET DIRECTIONS` link

Open `script.js` and change `birthdayDate` to the real birthday date/time.
